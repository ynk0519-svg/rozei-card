# 政策カード ワークシート（租税教室）

鹿児島法人会青年部会の租税教室で使う、税金の使いみちをグループで選ぶ学習アプリです。
紙のワークシートと同じ流れ（ルール1〜5）をそのままデジタル化しています。

**公開URL： https://ynk0519-svg.github.io/rozei-card/**

## 画面は3つ

| 役割 | 入り方 | できること |
|---|---|---|
| 生徒 | そのまま「生徒」 | カード選び → 見せ合い → グループの政策 → 理由 → 発表 |
| 先生 | 学校コード＋パスコード | クラス設定、班の進行確認、クラス／学校の集計、記録の書き出し |
| 運営（青年部会） | 運営パスコード（初期 0000） | 学校の登録、全体集計、学校別比較、カード管理、データ取り込み |

## 授業での使い方

1. 運営画面で学校を登録し、学校コードとパスコードを先生に渡す
2. 先生が端末ごとにログインし「クラス設定」でクラス名を入れてから、生徒にiPadを渡す
3. 生徒は班名とメンバーを入れてゲーム開始。終わると結果が端末に保存される
4. 先生が「この学校の記録を書き出す」でJSONを保存し、運営に送る
5. 運営が「記録ファイルを読みこむ」で集約（複数ファイル同時可）。CSV書き出しも可能

## データについて

- 記録はブラウザの保存領域に残ります（1班あたり約870バイト、約6,000班ぶん）
- 端末ごとに別々なので、授業後に必ず書き出してください
- `gas-code.gs` をGoogleスプレッドシートのApps Scriptに設置して
  運営設定に「送信先URL」を入れると、各校から自動で集約できます

## ファイル

- `index.html` … アプリ本体（1ファイル完結。カード画像も埋め込み済み）
- `gas-code.gs` … Googleスプレッドシート集約用スクリプト（任意）

## 更新のしかた

`index.html` を差し替えてコミットすると、GitHub Pages が自動で再デプロイします。
URLは変わらないので、学校に配ったリンクやQRコードはそのまま使えます。
